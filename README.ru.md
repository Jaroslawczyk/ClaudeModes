# model-advisor

[English](README.md) · **Русский**

Мод для Claude Code. Подсказывает самую дешёвую модель, силу (effort) и режим, которые справятся с задачей, и показывает, куда уходят токены и лимиты.

## Установка

```
/plugin marketplace add Jaroslawczyk/ClaudeModes
/plugin install model-advisor@claude-modes
```

Изменения мода подхватываются в новой сессии (новом чате).

## Что на экране

Над полем ввода два блока. Интерфейс на русском и английском: язык переключает кнопка `EN` / `RU` в строке «Этот чат» или команда `/lang`, выбор запоминается между чатами. По умолчанию русский.

**Совет.** Кнопка «🔍 Проверить промпт» оценивает то, что вы напечатали, и показывает модель, силу (●○○○○), режим и причину выбора.
- «Применить»: выбор действует на следующий ход.
- «Своё…»: выбрать модель, силу и режим вручную.
- «Закрепить»: выбор действует до конца сессии. «Сбросить» отменяет выбор.
- Для первого сообщения в чате модель выбирается автоматически.

**Статистика.** Четыре строки:

| Строка | Что показывает |
| --- | --- |
| Этот чат | заполненность контекста, токены, стоимость |
| Экономия | сэкономлено и упущено в этом чате и за всё время |
| Лимиты | 5 часов и неделя, время до сброса (`2ч 15м`, `3д 4ч`); обновляется само раз в 30 секунд |
| Граф | кнопка запуска `graphify update .` для папки сессии |

**Панель `/spend`.** Расход по моделям, по инструментам, самые дорогие ходы, расход самого советчика.

Команды: `/spend` открывает панель, `/advisor` скрывает или показывает совет, `/lang` переключает язык.

## Как выбирается модель

Главное правило: **начинать с самой дешёвой модели и подниматься только при признаках сложности.**

Вид задачи определяется по глаголам, а не по существительным: «что делает эта функция» остаётся вопросом, хотя в нём есть слово «функция». Правила лежат в `hooks/classify.ts` и проверяются сверху вниз:

| Признак в промпте | Выбор |
| --- | --- |
| архитектура, аудит, безопасность, `с нуля`, `весь проект` | Opus, high, plan |
| рефакторинг, миграция, фича, `реализуй`, интеграция, мод или плагин; 3 и больше шагов | Sonnet, medium, plan |
| одна маленькая правка: до 200 символов, не больше 1 файла, без кода, без слов про ошибки | Haiku, medium, accept edits |
| правка, где сначала нужно разобраться, с ошибкой или несколькими файлами | Sonnet, medium, accept edits |
| ошибка без просьбы править (`почему падает`) | Sonnet, medium |
| анализ кода (`проверь`, `сравни`, `найди`) с файлом или кодом | Sonnet, low |
| вопрос, обсуждение, текст, сравнение без кода | Haiku, low или medium |
| длинный запрос (300+ символов) без явной задачи | Sonnet, low; уточняет Haiku |

Выбор поднимается вверх только в этих случаях:
- **Прошлая попытка не удалась** (`опять`, `снова`, `не помогло`, `та же ошибка`): Haiku заменяется на Sonnet, сила на ступень выше.
- **4 файла и больше или промпт длиннее 1500 символов:** сила на ступень выше, Haiku заменяется на Sonnet.
- **Блок кода в промпте:** Haiku заменяется на Sonnet.

Слова `быстро`, `срочно`, `quick`, `asap` включают быстрый режим (`/fast`), но не для Opus.

**Когда спрашивается Haiku.** Только если ключевые слова не дали уверенного ответа (уверенность ниже 0.6): очень короткая или невнятная правка, длинный текст без задачи. Уверенный ответ эвристики не перебивается и не тратит токены, поэтому один и тот же промпт получает один и тот же совет.

**Предупреждение о смене модели.** Кэш контекста привязан к модели. Если сменить модель в длинном чате (от 30 тысяч токенов в контексте), весь контекст записывается в кэш заново, и первый ход может стоить больше, чем сэкономит смена. Тогда к совету добавляется пометка, например «смена модели пересчитает кэш 120k ток. (+$0.28 на 1-м ходе)». В длинном чате выгоднее начать новый чат.

## Граф (graphify)

- Кнопка в строке «Граф» запускает `graphify update .` в папке сессии. Это только разбор кода, без LLM и без токенов. Нужен установленный graphify (команда `graphify` в PATH).
- Если в папке уже есть граф (`graphify-out/graph.json`), он обновляется сам в конце хода, в котором Claude правил файлы через Edit или Write.
- Ходы без правок граф не трогают. Новый граф автоматически не строится, только кнопкой.
- Правки через Bash (скрипты, `sed`) мод не замечает.

## Что стоит запросов к модели

| Что | Стоимость |
| --- | --- |
| Совет по ключевым словам | бесплатно, считается локально |
| Совет от Haiku | только по кнопке и при неуверенной эвристике; low effort, до 120 токенов ответа, промпт до 4000 символов; повторная проверка того же текста берётся из кэша |
| Экономия, токены, лимиты | бесплатно: арифметика по данным, которые движок присылает после каждого шага |
| Граф | бесплатно: разбор кода без LLM |

Пока вы печатаете, запросы не отправляются. Вызовы Haiku видны в `/spend` отдельной строкой.

## Как считается экономия

- **Сэкономлено:** сколько стоили бы те же токены на модели чата минус сколько они стоили на модели, которую вы выбрали. Считается по ценам API.
- **Упущено:** совет предлагал модель дешевле, но его не применили.
- **Проценты лимита:** на подписке доллары не списываются. Мод замеряет, на сколько процентов сдвигает лимит 5 часов один доллар по ценам API, и переводит экономию в проценты. Замеры переносятся между чатами.

Цены зашиты в `hooks/register.tsx` (`PRICES`), за 1 млн токенов, вход и выход: Haiku $0.10 / $0.50, Sonnet $2 / $10, Opus $4 / $20. Если цены изменятся, их нужно обновить вручную.

## Насколько это полезно

- **Экономия появляется только при смене модели на более дешёвую.** Если чат уже на Haiku, экономить не на чем, и «сэкономлено» остаётся нулём.
- **«Сэкономлено» гипотетическое.** Это разница по ценам API, а не возвращённые деньги. Она показывает, какой выбор дешевле.
- **Совет может ошибаться.** Мод видит только текст промпта, а не реальную сложность задачи. Например, «добавь время до сброса лимита» выглядит маленькой правкой, хотя нужно разобраться в чужом коде. Ошибка вниз обычно дешёвая (повтор на Sonnet), но не бесплатная.
- **Проценты лимита приблизительные,** пока замеров мало.
- **Средняя экономия не измерена.** Чтобы её узнать, сравните `/spend` по моделям за несколько недель с модом и без него.

Итого: мод показывает, куда уходят токены и лимиты, и подталкивает к дешёвой модели там, где задача простая. Гарантированной экономии нет, она зависит от того, применяете ли вы совет.
